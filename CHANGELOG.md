## [1.0.0] - 2026-11-25

### Added
- First release: one pixel-art theme with dark and light mode.
- Pixel landscape behind dashboards: banded sky with dithered steps, stars or clouds, moon or sun with a dithered halo, hills, trees and houses.
- One art pixel size (2 px) for frames, shadows, landscape and cursor; pixel font sizes 16/24/32/48/64 px.
- Optional card-mod rules: stepped window frames with a pixel shadow, dithered fill and pixel cursor for switched-on tiles, block bars for tiles with the class `overworld-blocks`, pixel cursor in the sidebar.
- Switches on the companion module Overworld Pixels (pixel icons, pixel font) with `overworld-pixels: "on"`.
